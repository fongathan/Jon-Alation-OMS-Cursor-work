# Push one-pager to Google Doc (when All Google MCP is connected)

In Cursor chat, after enabling **user-all-google-mcp** in Settings → MCP:

```
Create a new Google Doc titled "Data Navigator — Approach One-Pager (May 2026)"
with mime_type application/vnd.google-apps.document, then insert the full text
from business-data-catalog/Data-Navigator-Approach-One-Pager.md using docs_insert_text.
Return the doc URL.
```

Manual upload (no MCP):

1. Upload `Data-Navigator-Approach-One-Pager.docx` to Google Drive.
2. Right-click → **Open with → Google Docs**.
