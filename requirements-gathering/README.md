## Overview

This folder contains the four key deliverables for **Documenting Current Use Requirements** as defined in the Product Brief:

## How to Use

1. **Review** — Read through each document to understand the structure.
2. **Validate** — Use during stakeholder interviews to confirm accuracy.
3. **Update** — Fill in checkboxes, notes, and "In Use" columns based on interviews.
4. **Capture** — Follow the Screenshot Library instructions to capture and annotate screenshots.
5. **Store screenshots** — Save in `screenshots/alation/` and `screenshots/oms/` subfolders.

---

## Workflow Diagrams (Mermaid)

The workflow document uses [Mermaid](https://mermaid.js.org/) for diagrams. To view them:

- **GitHub/GitLab** — Renders Mermaid natively
- **VS Code** — Install "Markdown Preview Mermaid Support" extension
- **Cursor** — Mermaid may render in preview
- **Online** — Paste at [mermaid.live](https://mermaid.live) to view/edit
