Alation Functionality Reference

Core functionalities with documentation links, explanations, and examples from Disney Data Alation

1

Search / Catalog Search

Full-text search across the catalog by keyword. Filter by object type (table, article, schema, column, datasource). Results are ranked by relevance and usage statistics.

2

Data Sources

Top-level connections to databases (Snowflake, PostgreSQL, etc.). Each source has schemas, tables, and columns. Alation extracts metadata, supports profiling, and runs Compose queries.
Example
  • Alation Analytics V2 — PostgreSQL, for user behavior and catalog analytics
  • Snowflake - DSS, Snowflake - Hulu, Snowflake - DTCI - UP
Adding Data Sources →
3

Schemas, Tables, and Columns

Hierarchical metadata: Data Source → Schema → Table → Column. Each level has descriptions, stewards, custom fields, and tags. Supports synonyms and popularity metrics.
Example
  • Schemas: CONFORMED, SUBSCRIPTIONS, SUBS
  • Tables: DIM_CUSTOMER, VIEW_DIM_CUSTOMER, DIM_CUSTOMER_TYPES
Working with Catalog Data →
4

Articles (Knowledge Base)

Rich-text documentation pages. Articles can be nested in folders, linked to data objects, and edited collaboratively. Used for stewardship frameworks, onboarding, and process docs.
Example
  • Data Stewardship Framework — Operating model, governing groups (DSComm, DSC, DWG)
  • Welcome to Alation — D.E.E.T. Data Catalog resources
Article example → · Document Hubs →
5

Business Glossary

Centralized definitions of business terms and metrics. Terms include descriptions, aliases, custom fields (Business Formula, Query, Stewards), and links to related queries or tables.
Example
  • Paid Subscribers — Dimensional cuts, business formulas, Compose query links
  • Total Time Streamed per Entitled Account (HPS) — Formula and SQL
D.E.E.T. Unified Glossary → · Alation Glossary →
6

Data Lineage

Visualizes upstream and downstream data flow for tables, columns, and dataflows. Auto-generated from query logs, metadata extraction, and Compose. Supports column-level and cross-source lineage.
Example
  • For VIEW_DIM_CUSTOMER: upstream source tables, downstream consumers
Table lineage example → · Discover Lineage →
7

Compose (Saved Queries)

SQL editor integrated with the catalog. Users write, save, and share queries. Saved queries appear in the catalog, contribute to lineage, and can be scheduled or exported.
Example
  • Glossary terms link to Compose queries (e.g., Metric table version, Metric build version)
Compose → · Alation Compose →
8

Dataflows

ETL/ELT jobs, stored procedures, or transformation pipelines. They appear in lineage and can be documented like tables.
Example
  • Filter by datasource_id to see ETL jobs for a given Snowflake or other source
9

Tags

Labels applied to catalog objects for classification, compliance, or discovery. Tags can have descriptions and show object counts.
Example
  • Core Table (28 objects) · GDPR Scoped (8) · CCPA Scoped (15)
  • Content360, Session360, Adobe — Domain/project tags
Tags →
10

Tagged Objects

Returns all catalog objects with a specific tag. Useful for compliance reporting (e.g., all "GDPR Scoped" tables).
11

Flags (Endorsements, Warnings, Deprecations)

Data quality signals: ENDORSEMENT = trusted, production-ready; WARNING = known issues; DEPRECATION = being phased out.
Example
  • Schemas endorsed by stewards indicate trusted data sources
12

Domains

Logical groupings by business area. Organize data by department, product, or use case. Objects can be filtered and searched by domain.
Example
  • Ad Platforms Domain · DEET Data Domain · Atlas Domain
Domains → · Domains Overview →
13

Custom Fields

Admin-defined attributes (Business Steward, Data Domain, Business Formula) on glossary terms, tables, columns. Supports text, users, groups, multi-select.
Example
  • "Paid Subscribers" has: Background Context, Data Domain, Aliases, Stewards, Business Segment
Custom Fields and Templates →
14

Folders

Organizational structure for articles. Folders can contain subfolders and articles for a clear knowledge base hierarchy.
15

Query Results & SQL

Retrieve query metadata, SQL text, and (where permitted) results for saved Compose queries. Supports sharing and exporting.
Work with Query Results →
16

Create/Update Articles

Create or update knowledge base articles via API. Supports rich HTML, attachments, and custom fields.
17

Update Custom Field Values

Programmatically set or update custom field values (e.g., assign a steward, update a description).
18

Get Current User

Returns the authenticated user's profile for API context and permissions.
